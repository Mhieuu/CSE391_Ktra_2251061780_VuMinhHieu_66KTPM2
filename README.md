Bài kiểm tra
=====================

Trang web tĩnh mẫu cho bài kiểm tra môn Nền tảng phát triển web.

Nội dung chính
- Tập tin chính: [index.html](index.html)
- Styles: css/style.css
- Script: js/script.js
- Dữ liệu mẫu: data.json

Chạy nhanh
- Mở `index.html` bằng trình duyệt hoặc chạy server tĩnh, ví dụ:

  ```bash
  python -m http.server 8000
  ```

Công nghệ
- HTML, CSS, JavaScript, Bootstrap

Tác giả
- Hiếu
